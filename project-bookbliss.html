About the Project
Overview

BookBliss is a community-driven platform built for readers to connect, share reviews, and track their literary journeys. Users can join reading challenges, participate in book discussions, and engage in a shared ecosystem centered around literature.

The platform was built with Laravel's MVC architecture, Blade templating for dynamic views, and MySQL for relational data. It features user authentication, profile management, book cataloguing, and a social discussion layer.

Built as a collaborative full-stack project, BookBliss demonstrated applying Laravel conventions and RESTful routing to a real-world community application.

Challenges & Solutions

Handling relational data between users, books, reviews, and challenges in MySQL without creating overly complex joins.

Designed a normalized schema with pivot tables for many-to-many relationships (users ↔ challenges, users ↔ books) and used Laravel Eloquent relationships to keep queries clean.

Authorization — ensuring users could only edit or delete their own reviews and profile data, not other users' content.

Implemented Laravel Gates and Policies to check ownership before any update or delete operation, keeping authorization logic centralized and reusable.
