About the Project
Overview

SignBridge is a real-time sign language translation system developed as a final-year group project. The system uses a CNN-based gesture recognition model to detect and interpret hand signs captured through a live camera feed.

The goal was to create an accessible communication bridge — converting hand gestures into readable text in real time, reducing the barrier between the hearing and deaf communities. The project focused on high-accuracy gesture detection under varying lighting conditions and hand positions.

The frontend displays live video alongside the translated output, while Python powered the model inference pipeline with a Flask backend handling real-time data streaming via WebSockets.

Key Features

Real-time Detection

Live camera feed processed frame-by-frame with sub-100ms inference latency using optimized CNN model weights.

CNN Gesture Model

Custom-trained convolutional neural network on Sri Lanka Sign Language dataset, achieving high accuracy across 26 gestures.

WebSocket Streaming

Socket.IO-powered bidirectional streaming between browser and Flask backend for seamless real-time translation output.

Accessibility Focus

Designed with deaf and hard-of-hearing users in mind — minimal UI friction, large text output, high contrast display.

Lighting Robustness

Model trained with augmented data to handle varied lighting conditions, backgrounds, and hand skin tones.

Deployed on Render

Full production deployment on Render with TURN server configuration for WebRTC cross-network video handling.

Challenges & Solutions

WebRTC video feed breaking across different network environments — STUN servers alone weren't enough for cross-network peer connections.

Configured a TURN server to relay media traffic, ensuring reliable connections regardless of NAT or firewall restrictions on the Render deployment.

gevent compatibility issues with Python 3.14 caused Socket.IO to crash on startup with monkey-patching errors.

Pinned the Python runtime to 3.11 in the Render environment and updated gevent to a compatible version, resolving all async conflicts.

Model accuracy dropped under low-light or high-contrast backgrounds, causing misclassification of similar gestures.

Augmented the training dataset with brightness, contrast, and rotation transforms. Retrained the CNN with dropout regularization to improve generalization.
