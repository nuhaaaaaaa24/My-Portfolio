About the Project
Overview

AquaTurtle is a web-based educational platform designed to raise awareness about Sri Lanka's diverse sea turtle species and their ecological importance. The site provides structured information on different species, their natural habitats, life cycles, and major threats including habitat destruction, marine pollution, and illegal poaching.

The platform promotes marine conservation by educating users and encouraging responsible environmental practices. It highlights ongoing conservation initiatives in Sri Lanka, giving users insight into how local efforts protect endangered sea turtles.

Built from scratch using pure HTML, CSS, and JavaScript during my first year — this project established my foundation in frontend development, responsive design, and web standards.

Key Features

Species Profiles

Dedicated pages for each of Sri Lanka's sea turtle species — covering appearance, habitat range, diet, and conservation status.

Conservation Focus

Highlights active turtle conservation projects in Sri Lanka with information on how users can support local environmental efforts.

Responsive Layout

Fully responsive design — adapts cleanly to all screen sizes using CSS Grid and Flexbox without any frameworks.

Life Cycle Visual

Interactive JavaScript-driven visual showing the sea turtle life cycle — from egg to adult — with descriptive overlays.

Photo Gallery

Curated image gallery of Sri Lankan sea turtles with lightbox functionality built in vanilla JavaScript.

Semantic HTML

Built with accessibility in mind — proper heading hierarchy, alt text on all images, and semantic HTML5 elements throughout.
