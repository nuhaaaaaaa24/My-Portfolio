About the Project
Overview

Budgetly is a smart budgeting app developed as a personal project to deepen full-stack JavaScript skills. The app helps users track income and expenses, categorize spending, and make informed financial decisions.

The app features a dashboard with Chart.js-powered pie and bar charts for spending visualization, a full transaction log with filtering, and a budget system with alert thresholds when limits are exceeded.

Built with JWT authentication, the MERN stack, and a focus on clean UX — Budgetly was designed as a real-world usable tool, not just a demo project.

Key Features

JWT Authentication

Secure user registration and login with JSON Web Tokens. Protected routes ensure only authenticated users access their data.

Transaction Management

Full CRUD for income and expense entries — categorized, filterable, and sortable with real-time balance updates.

Chart.js Analytics

Pie charts for spending by category and bar charts for monthly trends — giving users a clear financial picture at a glance.

Budget Alerts

Set monthly budgets per category. The app warns when spending approaches or exceeds the defined threshold.

RESTful API

Clean Express.js REST API with organized routes for auth, transactions, and budgets — built for scalability.

Responsive UI

Fully responsive React frontend — works cleanly across desktop, tablet, and mobile screen sizes.

Challenges & Solutions

Keeping the dashboard charts in sync with live transaction data without full page reloads was causing stale state issues.

Lifted state to a shared context provider and triggered chart re-renders via useEffect hooks tied to the transaction list dependency array.

Budget alert logic needed to compare cumulative spending per category against user-defined limits across all transactions.

Built a MongoDB aggregation pipeline to group transactions by category and month, then compared totals server-side before returning alert flags to the frontend.
